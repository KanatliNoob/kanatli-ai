KANATLI AI - GitHub Pages başlangıç dosyaları

Yayınlama:
1. GitHub'da yeni bir repository oluştur (ör. kanatli-ai-site).
2. Bu ZIP'i aç.
3. index.html dosyasını ve assets klasörünü repository'nin ana dizinine yükle.
4. Repository > Settings > Pages bölümüne gir.
5. Build and deployment altında Deploy from a branch seç.
6. Branch: main, folder: /(root) seç ve Save'e bas.
7. GitHub Pages adresinin oluşmasını bekle.

Not:
- Bu ilk sürüm yalnızca tanıtım/bekleme sayfasıdır.
- "Çıktığında Haber Ver" butonu şimdilik kayıt almıyor. Gerçek e-posta bildirimi için ayrıca bir form veya backend bağlanmalı.
